Read the 'AGENTS.md' file before starting.

We are adding the design system and UI primitive components.

Use shadcn UI component library. https://ui.shadcn.com/

Install and configure 'shadcn/ui'.

Add the shadcn components to the project.
- Button
- Card
- Input
- Label
- Select
- Textarea
- Badge
- Avatar
- Textarea
- Scrollarea
- Dialog
- Tabs

Dont modify the generated 'components/ui' after installation.

Also install 'lucide-react' 

Create a 'lib/utils.ts' with a reusable cn() healper for merging the tailwind classes.

Ensure all the components match the existing dark theme in the global.css

### Check when done
- All the shadcn components are installed and configured.
- All the shadcn components are matching the existing dark theme in the global.css
- cn() is working as expected
- no default light style appear
